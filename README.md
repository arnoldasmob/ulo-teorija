# ULO teorijos treniruoklis

Asmeninis pasiruošimo įrankis ultralengvųjų orlaivių piloto teorijos egzaminui: 14 dienų planas, klausimų treniruoklis su progreso sekimu, faktų lapai ir Aleksoto (EYKS) aerodromo duomenys.

Vienas savarankiškas `index.html`. Progresas saugomas naršyklėje (`localStorage`), į serverį nieko nesiunčiama.

Klausimai iš pilotai.lt teorijos testų, naudojami tik asmeniniam mokymuisi. Puslapis pažymėtas `noindex`.
